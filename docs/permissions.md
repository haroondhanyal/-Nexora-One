# Permission model

Roles are assigned by an authorized administrator and resolved from the server-side membership after sign-in. Portal icons and URL parameters never grant roles. API requests validate either the Keycloak JWT issuer/audience/signature or a tenant-scoped API client token, then check active membership, tenant, role and branch assignment. Tenant-keyed branch, business, invitation, audit and idempotency tables have PostgreSQL RLS in addition to query filters. UI checks only improve navigation; they are not security boundaries.

Local role templates include Owner, Admin, HR manager, Employee, Sales, Purchasing, Warehouse, Finance manager and Staff. The API preserves the final active owner, prevents admins from managing owners, checks branch assignment before record operations, rejects self-approval, protects posted records, uses optimistic versions and requires idempotency keys for create/update/status writes. Signed Odoo commands bind signatures to the tenant database. Keycloak handles login/TOTP/recovery; disabled memberships are denied on each API request. API clients issue random one-time bearer tokens stored as SHA-256 digests, scoped to one branch and a restricted role, with expiry and explicit revocation; revoked memberships invalidate their tokens. API-token runtime and security testing remains pending. Production support access, portal ownership and centralized identity-session revocation are not implemented yet.

Phase 3 adds `HR manager` and `Employee` membership roles. HR managers and workspace owners/admins manage employee, compensation and payroll data; employees can see their linked profile, attendance, leave and released payslips only. Payroll preparers cannot approve their own runs. Salary visibility is enforced by the API role and tenant checks and still needs dedicated leakage testing before phase exit.

Required authorization checks include forged tenant IDs, branch restrictions, own-record portal access, protected salary fields, exports, role revocation, disabled accounts, last-owner protection and support-access expiry.
